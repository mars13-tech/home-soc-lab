# Incident Response Lifecycle

Detection
→ Validation
→ Investigation
→ Containment
→ Eradication
→ Recovery
→ Lessons Learned

---

# Containment

Containment focuses on stopping attacker activity and preventing attack spread.

Examples:
- isolate endpoint
- disable accounts
- block malicious IPs

---

# Escalation

High-severity incidents should be escalated to senior responders for immediate action.

---

# Key Lessons

Strong SOC analysts:
- investigate thoroughly
- document clearly
- think operationally
- focus on response actions
