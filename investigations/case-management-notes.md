# SOC Case Management Notes

## Incident Workflow

Alert
→ Validation
→ Investigation
→ Escalation
→ Containment
→ Resolution

---

# Investigation Priorities

SOC analysts prioritize:
- confirmed malicious activity
- credential theft
- malware execution
- lateral movement
- persistence mechanisms

---

# Escalation Criteria

Escalate incidents involving:
- encoded PowerShell
- phishing activity
- malicious macros
- multiple affected systems
- suspicious network traffic

---

# Key Lessons

Professional SOC operations require:
- documentation
- evidence tracking
- timeline reconstruction
- investigation consistency
